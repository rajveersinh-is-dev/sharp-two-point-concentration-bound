# Sharp Two-Point Concentration Bound

A refined concentration inequality for sums of independent bounded random variables,
based on the sharp two-point (convexity/chord) moment-generating-function bound,
with an explicit improvement over Hoeffding's inequality and reproducible numerical
verification.

**Author:** Rajveersinh Vishal Pardeshi (Independent Researcher)

## Research question

Given independent random variables $X_i \in [a_i, b_i]$ with known means $\mu_i$,
how tightly can $\Pr\{\sum_i X_i \ge \sum_i \mu_i + t\}$ be bounded using only the
ranges and means? Can the sharp two-point MGF bound be retained (instead of
Hoeffding's $e^{\lambda^2(b-a)^2/8}$ relaxation) to get a strictly better bound?

## Contribution

- **Theorem 1:** an explicit Chernoff-style tail bound as a one-dimensional infimum
  over $\lambda>0$, using the sharp two-point MGF bound and the individual means.
- **Corollary 1:** homogeneous Bernoulli case $\Rightarrow$ binomial Cramér rate
  $\exp(-n D(q\|m))$, strictly sharper than Hoeffding's $\exp(-2n(q-m)^2)$ for
  $q\ne m$ (strict Pinsker); improvement factor unbounded as $m\to0$.
- **Reproducible numerical validation:** Monte Carlo, comparison to Hoeffding/
  Bernstein, tightness against exact binomial tails (fixed seeds, standard library).

## Status of the findings

**Incremental / expository refinement.** The underlying two-point MGF bound is
classical (Hoeffding, 1963); the Bernoulli worst-case MGF fact is standard. This
work assembles it into an explicit bound, quantifies the strict improvement over
Hoeffding, and verifies it numerically. It is **not** a new fundamental inequality,
and is **not** claimed to be state of the art. See `research/novelty_assessment.md`
and `research/hostile_review.md`.

## How to reproduce the results

```bash
# Numerical tables and figure
python scripts/table_values.py        # Table 1 values (seed 7, 1e5 trials)
python scripts/fig_compare.py         # Figure 1 (figures/fig1_compare.pdf/png)

# Automated correctness tests
python tests/test_concentration.py
```

All experiments use fixed seeds; `src/concentration.py` and `src/analysis.py`
contain the implementation. Python 3.14+; the core code uses only the standard
library (matplotlib is used only by `scripts/fig_compare.py`).
