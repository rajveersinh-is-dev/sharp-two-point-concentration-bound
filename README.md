Sharp two-point MGF concentration bound: an explicit improvement over Hoeffding's inequality with reproducible numerical verification. Incremental refinement of Hoeffding (1963).

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/rajveersinh-is-dev/sharp-two-point-concentration-bound.git
cd sharp-two-point-concentration-bound
python "scripts/fig_compare.py" --help
```

## Testing

pytest tests/
